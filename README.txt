AKSHITHA JAMMU — PORTFOLIO WEBSITE

Files:
- index.html: complete responsive portfolio website.

Preview:
- Double-click index.html to open it in a browser.

Publish it:
1. Create a GitHub repository named akshitha-portfolio.
2. Upload index.html.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. After GitHub Pages publishes it, your website URL will be:
   https://akshithajammu22-byte.github.io/akshitha-portfolio/

Before publishing:
- Check every project description and update anything that has changed.
- Add GitHub repository links for each project if available.
- Add a resume PDF link if you want visitors to download your resume.
